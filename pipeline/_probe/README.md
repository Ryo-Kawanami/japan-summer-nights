# 調査用スクリプト

本番のパイプラインではない。設計時の確認と、地図の目視チェックのためのもの。

| ファイル | 内容 |
|---|---|
| `listall.py` | JAXA Earth API の全119コレクションを列挙し、温度に関わるものを抽出する |
| `visual_check.py` | 数値の再確認と、昼夜×前後期の地図を1枚の PNG に並べる。UI に手を入れる前にここを見る |
| `series.log` / `series_night.log` | 初回調査時の取得ログ。当時は bbox が狭く大陸を含んでいたため、数値は現行と異なる |
| `fetch_wide.log` | 現行 bbox（沖縄を含む）での取得ログ |

初回調査に使った `series.py` / `trend.py` / `final.py` は
`pipeline/fetch.py` と `pipeline/aggregate.py` に置き換わったので削除した。

## 経緯の記録

初回調査では bbox `[128, 30, 146, 46]` を使っており、韓国・ロシア・中国大陸が
集計に混ざっていた。また沖縄が範囲外だった。そのため当時の数値は

    昼 +0.086℃/10年 (t=0.61)   夜 +0.561℃/10年 (t=3.39)

で、現行の日本限定・沖縄込みの値とは異なる。結論（昼は有意でない、夜は有意）は
変わらないが、昼の t は 0.61 から 1.94 へ上がり、判定境界に近づいた。

`series*.log` を残しているのは、この差分の出所を後から辿れるようにするため。

## 過去に踏んだ間違い

- 配列を上下反転させて描画し、列島が逆向きになった。row 0 は北。反転は不要
- 「上昇したピクセルの割合」を計算するとき、海の NaN を分母に入れて 29% と出した。
  実際は陸だけで見て 99.9%。`aggregate.land_fraction_warming` が正しい実装
- 量子化誤差とレンジ外の切り捨てを混ぜて測り、「量子化が粗い」と誤読しかけた。
  この2つは別物なので分けて測る
- 地理の健全性を「緯度順に単調」で判定して誤警報を出した。東京は都市の影響で
  鹿児島より夜が暑い。判定は全画素の相関で行う
